## 🔧 TROUBLESHOOTING TIPS:

If Sora still clips or has issues:

### Remove these words (AI struggles):
- "slumped" ❌
- "frantically" ❌
- "overwhelmed" ❌
- Complex emotions ❌

### Use these instead:
- "sitting" ✅
- "quickly" ✅
- "excited" ✅
- Simple emotions ✅

### Better structure:
```
[Scene description]. [Action]. [Result]. Duration 9 seconds, no dialogue.
```

### Keep it simple:
- One location = better
- Clear actions = better
- Specific objects (toys, tablet) = better
- Vague concepts (responsibility, growth) = worse

## 📝 PROMPT FORMULA THAT WORKS:

```
[Subject] + [Initial state] + [Action] + [Transformation] + [Result/Payoff] + [Branding] + [Technical specs]
```

**Example:**
- Subject: Child age 9
- Initial state: Bored on couch with messy room
- Action: Looks at tablet (Chore Me)
- Transformation: Excitedly cleans room
- Result: Gets reward coins, high-fives parent
- Branding: "Chore Me" text
- Technical: 9 seconds, bright home, upbeat music, no dialogue
